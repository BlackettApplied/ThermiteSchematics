# Machine demonstration build

This is a synthetic machine documentation demonstration with illustrative
equipment and wiring. Preserve existing
user examples, legacy rendering and guarded agent contracts. Develop on Apple
Silicon macOS only. No publication or license change is part of this work.

## Acceptance plan

- [x] Bounded compact layout selection with measured page-count/readability checks.
- [x] Terminal and PLC I/O views; BOM, wire/cable/I/O schedules and packet index.
- [x] Stable identity-based change review and affected-device reporting.
- [x] Small source-documented Siemens library with explicit modeling limits.
- [x] Searchable, linked packet viewer and repeatable local PDF export.
- [x] Representative two-cabinet machine demo and a guarded change demonstration.
- [x] Regression, negative-case and visual checks; run guide.
- [x] Fresh source archive acceptance.

Layout must keep readable text, exact topology, complete conductor inventories
and paired continuations. Reports derive from compiled project facts. Unknown
part information, unused channels and incomplete terminations must remain explicit.
Manufacturer documentation must support exact terminal mappings; do not extrapolate
between models. Public licensing and actual machine engineering remain owner decisions.

## Implemented scope

- Bounded three-candidate ELK selection, same-sheet folding, separate header
  space for zones/captions/continuations and readable table wrapping.
- Terminal, I/O, BOM, wire/core and cable reports, CSV export, content index and
  device/function references. The demo contains 20 devices, 54 wires, 3 jumpers,
  32 channels, 16 strip terminals and all four cable cores.
- Identity-based semantic snapshot/review, with an executable guarded LS1 change.
- Three exact Siemens order numbers with official terminal evidence and explicit
  limits. Libraries remain visible local JSON, protected by byte locks.
- Responsive searchable HTML, sheet links, polling regeneration and direct vector
  PDF output with embedded OFL fonts and deterministic metadata.
- Product version 0.3.0-alpha.2; workspace packages use the @thermite scope.

## Known boundaries

The pilot does not configure PLCs, validate PLC address-range overlap, select
ET 200SP BaseUnits/interfaces, estimate unmodeled hardware, or engineer a press
safety system. It does not promise stable sheet numbering or incremental layout
positions after edits. Safari and physical printer acceptance need a user check;
only Apple Silicon macOS was exercised. Public release licensing is unchanged.
