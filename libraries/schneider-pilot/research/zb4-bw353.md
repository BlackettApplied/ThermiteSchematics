Mapping the job's presentation hyphen is an identity interpretation supported by the otherwise exact character sequence and S3's matching yellow, momentary illuminated-head description. Searches for the literal hyphenated spelling on manufacturer domains returned no results; no manufacturer alias declaration was found. No suffix was added or removed.

The historical “Signal light Yellow” description is broader than the supplied component: this is an operator head, not a complete electrical lamp. Yellow agrees with S3; orange agrees with S1/S2. Preserve this manufacturer/source discrepancy without substituting a different order code or asserting an as-built lens color.
