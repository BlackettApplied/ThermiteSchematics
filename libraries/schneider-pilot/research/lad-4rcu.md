# Schneider Electric LAD-4RCU — lad-4rcu

Decision: **candidate**, with partial physical connection coverage. Proposed identity is exactly `schneider-pilot:lad-4rcu`, manufacturer `Schneider Electric`, order `LAD-4RCU`. Schneider spells the reference **LAD4RCU**. Treating the source hyphen as a presentation separator is supported by the exact RC technology, voltage band, mounting method and D09–D38 / DT20–DT40 compatibility match; no successor or expanded assembly is substituted.

Evidence reviewed:

Connection specification independently derived from S1/S2: one passive two-ended RC network, plugged across its separately ordered host's coil. `RC.1` and `RC.2` are **unordered functional authoring aliases**, not manufacturer numbers, polarity, top/bottom positions, or an asserted one-to-one A1/A2 physical map. There are no documented external screw/wire terminals on the suppressor. No host main/auxiliary/coil terminals are imported into this accessory. Coverage is partial because contact markings and exact physical mating-position mapping are not documented. No PE, shield, communication or additional connection is established by the reviewed schematic.

Factory continuity: **no fixed links** between the two ends; the resistor/capacitor impedance must never become a net union. Installation joins each end to a different host coil node, but no cross-device joins are embedded in this standalone type. Both endpoints are required for this installed-suppressor model; both must engage the intended host for suppression to function.

Rendering uses the existing generic `load` circuit symbol for the entire passive RC network. The available symbols lack a dedicated RC suppressor mark; the model preserves function and two endpoints without fabricating resistor/capacitor geometry or an inaccessible internal junction. It is not an impedance simulation or a host-fit/as-built validation.
