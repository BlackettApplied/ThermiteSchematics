## Terminal and function inventory

| Keys       | Function                        | Normal state | Universally required |
| ---------- | ------------------------------- | ------------ | -------------------- |
| `11`, `12` | `nc`, mapped to `pushbutton-nc` | Closed       | No                   |
| `13`, `14` | `no`, mapped to `pushbutton-no` | Open         | No                   |

The drawing has two separate pushbutton actuators. The model has no ganged
relation and creates no internal conductive joins, including across the
normally closed contact. All four nets remain separate without project wires or
jumpers. The operator has no documented lighting, power-supply, return, shield,
communication or PE connection in the reviewed exact circuit. No such terminal
is invented. A containing enclosure's bonding inventory must be reviewed as part
of that separately specified assembly.

Coverage remains **partial** because the exact fitted contact-block revision,
screw/spring termination choice and physical clamp inventory are unverified. No scalar terminal voltage/current rating is encoded, because
that would discard the utilization, power and temperature conditions and imply
an exact configuration capability that has not been established.

The circuit diagram does not identify each actuator by colour; the library
therefore uses `nc` and `no` function names and does not claim which physical
button or left/right position operates each contact. The specified face labels
remain documented. Before using this as an installed station, reconcile the
actual actuator/contact arrangement and block markings against the build.

## Focused verification

The [isolated example](../examples/23d01ba05/README.md) contains one manufacturer
component and one synthetic four-point boundary. Normal verification checks the
committed example and library lock. The optional `--isolated` mode creates a
private library snapshot containing only this type, locks it and validates it,
so concurrent library additions cannot change that run's byte lock. It checks both
normal states, four separate nets, no phantom PE/lighting contacts, passive
terminal omission, explicit conductor continuity, unknown-terminal rejection,
and stale library-byte rejection. The packet includes both functions and all
four wires, using the catalog's existing pushbutton marks. Render coverage and
visual QA are recorded with the example.
