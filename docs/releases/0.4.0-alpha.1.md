# Thermite Schematics 0.4.0-alpha.1

Public alpha release superseding `v0.3.0-alpha.2` (2026-09-23). Public releases
ship as verified Bun 1.4.2 runtime ZIP packages (see the
[runtime packaging guide](../runtime-package.md)); the legacy private `0.2.0`
npm tarball release path is retired (archived in the
[historical private release checklist](../legacy/private-release.md)).

## Drawing and layout

- **Presentation `0.3` and compact drawing frames**: added compact sheet frames
  with supplied title-block fields, revision history rows, configurable
  generator-stamp placement, and per-sheet geometry budgets
  ([drawing frames](../drawing-frames.md)).
- **Literal 2.5 mm printed text floor**: raised all printed text runs across
  SVG, HTML, and PDF (including frame furniture, zone markers, notes, footers,
  captions, and references) to at least 2.5 mm vertical physical em, preserving
  the 2.7 mm floor for device designation tags and using one pinned-font
  text-measurement module.
- **Function-based circuit views and symbols**: unified printable symbols and
  text across views, bound rooted views by catalog profile, added function-level
  circuit symbols, protection/auxiliary role marks, open-disconnector and
  transformer-secondary control bindings, upright AC/DC polarity qualifiers, and
  authored-only receptacle earth openings ([circuit views](../circuit-views.md),
  [circuit symbols](../circuit-symbols.md)).
- **Signal loops and terminal strips**: added series-powered signal-loop
  selection, polarity checks, and drawings ([signal loops](../signal-loops.md));
  drew native terminal strips with reciprocal inventory references and
  side-by-side strip composition on shared sheets.
- **Pagination, navigation, and folding**: paginated oversized circuit,
  communication, and protective-cap views with destination `sheet.zone` and wire
  numbers on continuations; added ink-based rooted sheet folding, coil/contact
  mirror tables, hidden-detail companion inventories, off-view connection
  disclosure, compact element locators, and spacing-aware rooted top-to-bottom
  fit retries with more specific R006 diagnostics.
- **Routing and label clearance**: improved inline circuit wire labels,
  separation of coincident circuit routes and physical wire landings, open-end
  caption and multi-lead stub clearance, self-loop label placement, and
  preservation of native PDF label clips.

## Agent CLI and guide

- **Offline runtime guide and schemas**: added `thermite guide` topics,
  `guide symbols`, `guide diagnostics`, `guide schema`, and executable starter
  requests in `thermite agent <tool> --help`, backed by resolved offline copies
  in runtime packages.
- **Guarded source patching and recovery**: `inspect` and `resolve` now return
  guarded source pointers; guarded patches serialize writes through
  `.thermite-schematics-write.lock`, support repairing schema-invalid sources,
  and report valid alternatives in diagnostics and agent errors.
- **CLI ergonomics and project guide**: added project path aliases and matching
  `--project` acceptance for `validate`/`lock`, kept the generated project
  `AGENTS.md` compact and aligned with the guarded workflow, and separated the
  frozen historical guide from active project instructions.

## Exports and reports

- **Single-snapshot export bundles and freshness checks**: added
  `thermite export bundle` and `thermite export check` (plus standalone export
  receipts) binding authored source, library, lock, request, and producer
  identities to emitted packets, reports, and reviews.
- **Packet HTML unification and privacy**: unified standalone and embedded
  packet HTML output and kept local machine identities out of issued packets.
- **Reports and reference filtering**: added scoped report and packet reference
  filtering ([report filtering](../report-filtering.md)), native connector I/O
  assignments and socket schedules ([connector I/O](../connector-io.md)),
  column-scoped empty states, wire-schedule `sheet.zone` columns, one-line
  report identifiers, and preserved authored requirements in printable reports.

## Libraries and core 0.2.0

- **Shipped `core 0.2.0` beside frozen `core 0.1.0`**: expanded the shipped
  generic library to 33 provisional types (29 devices and 4 cables) covering
  operator, protection, power, automation, and instrumentation interfaces, while
  keeping `core 0.1.0` byte-frozen; `thermite init` now copies `core 0.2.0` into
  new projects ([core library guide](../../packages/core-library/README.md)).
  `core 0.2.0` freezes once `v0.4.0-alpha.1` is tagged.
- **Explicit catalog coverage**: added declared generic/partial catalog
  connection coverage metadata so unmodeled hardware interfaces stay visible in
  completeness audits.

## Validation and diagnostics

- **Voltage assessment and completeness**: warned on conflicting comparable
  declared ratings in undeclared net voltage fields (`W303`), reported
  voltage-assessment gaps for unassessed multi-rated and single-rated nets
  (`I304`/`I305`), skipped checks (`I208`), unsupported symbol profiles, and
  undrawn terminals in view selection; fixed partial-potential assessment and
  duplicate deferred-gap warnings ([validation](../validation.md),
  [completeness](../completeness.md)).
- **Declared physical continuity checks**: added `thermite continuity` and
  `continuity-check-request/0.1` / `physical-continuity-report/0.1` to audit
  explicitly declared physical continuity obligations without altering net
  semantics ([continuity checks](../continuity-checks.md)).
- **Render failure diagnostics**: named designations in R-codes, warned on
  incomplete drawing packets, and reported binding constraints after boundary-cut
  retries.

## Platforms, CI and packaging

- **Retired private `0.2.0` npm pipeline**: removed the legacy private npm
  tarball release workflows, scripts, and inventories; public releases ship
  solely through verified runtime ZIP packages on GitHub Releases.
- **Three-OS release matrix and worktree checks**: pinned macOS CI to
  `macos-15`, added parallel linked-worktree checks (`check-worktree.mjs`),
  pinned Playwright Chromium across macOS, Linux, and Windows, improved Windows
  guarded writes and cross-platform font resolution, and documented platform
  limits ([platform checks](../platforms.md)).
- **Documentation and quality checks**: added the generated
  [documentation index](../README.md), local link/navigation/legacy-quarantine
  checks (`check:docs`), executable documentation example verification, and
  contributor code-health and render-performance checks.

## Upgrading from `v0.3.0-alpha.2`

Extract the new runtime ZIP into a separate folder alongside Bun 1.4.2 and
switch your invocation path deliberately; do not overwrite an existing runtime
folder or patch files inside it. Review validation diagnostics and regenerated
drawings before issuing updated documentation. Validation checks the authored
model within supported rules and does not certify electrical safety or
code compliance; every generated schematic requires qualified engineering
review.
