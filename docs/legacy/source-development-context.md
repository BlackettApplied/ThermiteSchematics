# Source development and release context

This is a historical archive of the retired private npm tarball distribution.
Its build, install and evidence procedures are no longer available in this
checkout. Releases now ship through the [runtime package](../runtime-package.md).
Current development instructions are in the [repository README](../../README.md),
[CONTRIBUTING](../../CONTRIBUTING.md) and the [root guide](../../AGENTS.md).

The original [private release checklist](private-release.md) and
[legacy agent guide](private-release-agent-guide.md) preserve the historical
installation, project and guarded-tool context. They are records, not current
release authority or instructions for publishing a runtime package.

The retained `package-lock.json` records historical dependencies. Development
and current runtime packaging use `bun.lock`.
